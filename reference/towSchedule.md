# Tow schedules of IEP surveys

Replicated tow schedules for IEP surveys

## Usage

``` r
towSchedule
```

## Format

A list of data frames of each survey. Each data frame has 4 columns

- duration:

  Tow duration

- maxDepth:

  Maximum depth recorded at sampling location

- depth:

  Depth range label created by the cut() function

- cableLength:

  Length of cable to be let out
