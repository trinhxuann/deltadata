# Meter schedules of IEP surveys

Data frame outlining the acceptable flowmeter range per tow duration

## Usage

``` r
meterSchedule
```

## Format

A list of data frames of each survey. Each data frame has 4 columns

- duration:

  Tow duration

- meterMin:

  Minimum acceptable value

- meterMax:

  Maximum acceptable value

- gear:

  Gear type, leave as NA if none
